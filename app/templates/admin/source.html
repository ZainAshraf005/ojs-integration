OJS plugin setup for this install

Download plugin{% if plugin_version %} v{{ plugin_version }}{% endif %}

The plugin sends new and unpublished articles here within a minute and shows each article's ID on its OJS page, under the keywords (e.g. DOI: 1003/165, linked). Without it, new articles still arrive with the nightly sync (02:00), but OJS won't show the link.

  1. Download archiveSync.tar.gz with the button above. Don't unpack it.
  2. Upload it to OJS. Log in to {{ source.base_url }} as the site administrator, open any journal, then go to Settings → Website → Plugins → Upload a New Plugin, choose the file and click Save. One upload covers every journal in this install, and there is nothing to enable per journal. If an older version is installed, OJS offers to upgrade it instead.
  3. Connect it to the archive. In Hostinger File Manager, open this install's folder (where index.php is), edit config.inc.php, paste this block at the very end and save: {% set snippet = '[archivesync]\nwebhook_url = "' ~ webhook_url ~ '"\nwebhook_secret = "' ~ source.webhook_secret ~ '"' %} 
    {{ snippet }}
    Optional: add e.g. label = "Permanent link" on its own line to show another label instead of "DOI". Keep the secret private: it proves notifications come from this install.
  4. Push links for existing articles. Click Sync now at the top of this page. About a minute later every archived article shows its ID in OJS.
  5. Test it. Publish an article (or unpublish and republish one). The Activity log should show a webhook entry right away and an ojs-id entry about a minute later.
