Getting the API key
  1. In that install's config.inc.php, under [security], make sure api_key_secret has a value (set it once, then never change it).
  2. Log in to OJS as the site admin.
  3. Your name (top right) → Edit Profile → API Key.
  4. Tick "Enable external applications…", click Generate API Key, save, and copy it here.
